1. Why this is a good project

The project forces us to answer real engineering questions.

For example:

Where does the video go?

OPFS.

Where do we store the video's name?

IndexedDB.

Where do we store the MIME type?

IndexedDB.

Where do we store the actual binary data?

OPFS.

How do we find a video?

Search IndexedDB.

How do we display it?

Find its metadata in IndexedDB → locate the file in OPFS → obtain a File → create a browser URL.

What happens when deleting?

Remove the actual file from OPFS and its metadata from IndexedDB.

So we're not artificially combining the two APIs.

They genuinely have different responsibilities.
